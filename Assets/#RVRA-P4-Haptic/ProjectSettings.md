1. Buat proyek baru bernama RVRA-P4-Haptic dengan template 3D.

2. Buka Edit > Project Settings > Player > Other Settings > Active Input Handling, lalu pilih Both. Pengaturan ini memungkinkan keyboard lama dan getaran gamepad baru berjalan bersamaan.

3. Pasang package Input System melalui Window > Package Manager > Unity Registry bila belum ada. Unity akan meminta restart editor.

4. Salin berkas HapticFeedbackLab.cs dan MaterialHaptik.cs ke folder Assets/Scripts/.
